# 口语转书面

本文件列出常见的口语说法和对应的书面说法。词表是线索，不是替换规则。替换前看上下文；替换后，意思和确定程度要和原文一致。

## 动词和动作

| 口语 | 书面 | 说明 |
|---|---|---|
| 取数 | 数据接入、数据获取 | |
| 出结果、出报告 | 生成结果、出具报告 | |
| 接数据、上模块、回原平台、算收益 | 数据接入、模块上线、结果回写、成效评估 | 步骤名用名词短语 |
| 用起来 | 投入应用、发挥价值 | |
| 做方案 | 制定方案、方案设计 | |
| 搞定、弄好 | 完成、落实 | |
| 看一下、查一下 | 评估、核查 | |
| 一起推 | 共同推广 | |
| 跑通后一起复制 | 验证后共同规模化复制 | |
| 说明原因 | 解析成因、分析原因 | |
| 配上 | 叠加、集成 | |
| 自动出 | 自动生成 | |
| 省钱、省人 | 降低成本、减少人工投入 | |
| 不用配合开发 | 无需配合开发 | |
| 不改原平台 | 原平台零改造 | |

## 描述和判断

| 口语 | 书面 | 说明 |
|---|---|---|
| 领导要一个数，要等人做表 | 管理层临时取数需人工统计，响应滞后 | 场景描述写成"现状＋后果" |
| 做得最深的 | 积累最深的领域 | |
| 测评过关 | 通过测评 | |
| 在……场景里打磨 | 源自……真实项目 | |
| 成本低 | 高性价比、成本可控 | |
| 很多、好多 | 大量、众多 | |
| 马上、很快 | 即时、快速 | |
| 有点慢 | 响应滞后 | |
| 挺好、不错 | 删掉，或换成具体结果 | |
| 东西 | 产品、方案、系统 | 按实际所指 |
| 钱 | 费用、投入、成本 | |
| 想法 | 设想、思路 | |

**保留确定程度。** 原文有保留时，改写也要保留。"问题不大"不能改成"风险可控"，可以改成"预计影响有限"。"应该能做到"不能改成"可实现"，可以改成"预计可实现"。

## 函件和邮件

- **称呼**：对方单位用贵司、贵单位或贵方，己方用我司或我方。同一封函里不混用。
- **请求**：麻烦你们 → 烦请贵方；尽快回复 → 盼复。有截止日期就写日期："请于 11 月 15 日前回复"。
- **结尾**：正式函件用"此致　敬礼"；邮件可用"顺颂商祺"或"祝好"。一句"期待与贵方合作"可以保留；"让我们携手共创美好未来"这类套话删掉（见 [ai-patterns.md](ai-patterns.md) 第 12 条）。
- **邮件比函件宽松**：保留问候和感谢，正文仍用书面词。
